# Input Field

Input Field is a native text input with optional label, supporting text,
prefix/suffix content, tooltip icon, and password guidance. The Storybook
toolbar switches between SDS Light and SDS Dark.

## States and value presentation

`state` selects the Default, Error, or Disabled appearance. Error state styling
is independent of `hasError`: the state controls the border and
`aria-invalid`, while `hasError` controls whether the error message is shown.
Disabled also sets the native `disabled` attribute.

`valueType="Default"` uses `valueText` as the uncontrolled input value. When
`valueText` changes while the input is uncontrolled, its displayed value is
synchronized immediately, while ordinary user typing remains editable.
`valueType="Placeholder"` uses `valueText` as the placeholder and clears a
value previously derived from Default mode when switching modes. Native
`value` remains controlled, and an explicit `defaultValue` keeps its native
initial-value behavior. Use the native `placeholder` prop for a custom
placeholder.

## Label, description, and error

The Figma structure binds `hasLabel` to the visibility of the whole Group Title
frame and `showLabel` to the Label text layer. They remain separate props:
`hasLabel` removes the visible title row, while `showLabel` hides only its
visible text. The input retains a visually hidden associated label when the
text is not displayed; if the visible label group is omitted, pass a meaningful
`aria-label` when the `label` prop is not appropriate as its accessible name.

Set `hasDescription` and `hasError` to show their respective supporting text.
Both can be displayed together and are associated with the input through
`aria-describedby`. Supporting text extends below the 43px input frame.

## Prefix, suffix, tooltip, and password caption

Prefix and suffix text appear only when their corresponding `show...Text`
property is enabled. Icons are optional consumer-supplied React nodes; no icon
is rendered by default. `showTooltip` renders the supplied `tooltipIcon` only
when enabled. The reusable `InfoAlertIcon` shows the intended information
circle with an exclamation mark. `tooltipText` sets its accessible name and
native title; it defaults to “More information”. The Playground supplies
`InfoAlertIcon` for the tooltip and
`PlusIcon` for the prefix and suffix, so each Boolean control can be toggled
without first configuring a React node. The dedicated slot examples show how a
consumer can supply icon content. Prefix and suffix text controls operate
independently from the icon controls.

The password caption contains three independently configurable requirement
items. `showPasswordCaption` controls the visibility of the complete group.
`passwordRequirements` supplies each item's text and status. Each status selects
its icon automatically at 16px; callers cannot override the icon separately.
Both the Playground and the dedicated Password Requirements story expose three
independent text controls and three independent status dropdowns rather than an
array editor. Each status dropdown offers `default`, `positive`, and `error`.
Storybook maps those six controls to the `passwordRequirements` array. The raw
array prop stays hidden from Controls, while `showPasswordCaption` remains a
Boolean control. Changes appear in the preview immediately.

When `showPasswordCaption` is false, the whole requirements group is omitted
and its ID is excluded from the input's `aria-describedby`. When true, all
three items render and the group ID is included in `aria-describedby`.

## Dimensions and layout

| Property | Figma measurement |
| --- | ---: |
| Default and Placeholder widths | 212px / 209px in Figma |
| Input height | 43px |
| Horizontal / vertical padding | 16px / 12px |
| Border / radius | 1px / 8px |
| Content gap | 8px |
| Label row / label-to-input gap | 22px / 8px |

The React component fills its available container by default
(`width: 100%`). Set a width on the component through `className`, normal CSS,
or a wrapper when a fixed or constrained size is needed. The audited Figma
widths above are references rather than React variants.

## Themes and interaction

Default background, text, border, error, and spacing styles use generated
semantic tokens. The verified `border/disabled/secondary` token
(`3919:36533`) is missing from the generated CSS snapshot. No existing
disabled-border token is equivalent, so this component temporarily uses the
Figma Light (`#B2B2B2`) and Dark (`#10191B`) values in a scoped CSS fallback.
Replace that fallback when the token is added to the generated snapshot.

The component does not invent hover or pressed appearances. A visible
`:focus-within` outline is included for keyboard accessibility.

## Accessibility

- The visible label is associated with the input using a native `<label>`.
- When label text is visually hidden, it remains associated for assistive
  technology. If no suitable label text is available, pass `aria-label`.
- Description, error, and password guidance IDs are included in
  `aria-describedby` when those contents are shown.
- When `showPasswordCaption` is true, the requirement group is included in
  `aria-describedby`. Requirement icons are decorative; visually hidden status
  text communicates whether a requirement is met, unmet, or neutral.
- Error state sets `aria-invalid`; native disabled, keyboard editing, and input
  types such as `password` are preserved.
- `prefixIcon`, `suffixIcon`, and `tooltipIcon` are optional consumer-provided
  slots. Prefix and suffix icons are decorative; use text or other accessible
  labeling to communicate field meaning.

## API reference

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `state` | `'Default' \| 'Error' \| 'Disabled'` | `'Default'` | Visual state; Error sets `aria-invalid`, Disabled sets native disabled. |
| `valueType` | `'Default' \| 'Placeholder'` | `'Default'` | Chooses whether `valueText` is an initial value or placeholder. |
| `valueText` | `string` | `'Value'` | Figma Value text used for the uncontrolled Default value or Placeholder text; updates synchronize with the selected mode. |
| `hasLabel` | `boolean` | `true` | Shows the Figma Group Title row. |
| `showLabel` | `boolean` | `true` | Shows label text inside the title row. |
| `label` | `ReactNode` | `'Label'` | Associated visible or visually hidden input label. |
| `hasDescription` | `boolean` | `false` | Shows `description` below the input. |
| `description` | `ReactNode` | `'Description'` | Supporting description text. |
| `hasError` | `boolean` | `false` | Shows `error` below the input. |
| `error` | `ReactNode` | `'Error'` | Error message; independent of visual Error state. |
| `showPrefixIcon` / `prefixIcon` | `boolean` / `ReactNode` | `false` / `undefined` | Shows a supplied leading icon. |
| `showSuffixIcon` / `suffixIcon` | `boolean` / `ReactNode` | `false` / `undefined` | Shows a supplied trailing icon. |
| `showPrefixText` / `prefixText` | `boolean` / `string` | `false` / `'$'` | Shows leading text. |
| `showSuffixText` / `suffixText` | `boolean` / `string` | `false` / `'USD'` | Shows trailing text. |
| `showTooltip` / `tooltipIcon` | `boolean` / `ReactNode` | `false` / `undefined` | Shows a supplied icon only within the visible title row. |
| `tooltipText` | `string` | `'More information'` | Accessible name and native title for the supplied tooltip icon. |
| `showPasswordCaption` | `boolean` | `false` | Shows all three requirements; when hidden, the group is omitted from `aria-describedby`. |
| `passwordRequirements` | `[PasswordRequirement, PasswordRequirement, PasswordRequirement]` | Three default-status guidance items | Text and status for each of the three password requirements. |
| `className` | `string` | `undefined` | Additional class on the component wrapper. |

`PasswordRequirement` is the item type:

```ts
export type PasswordRequirementStatus = 'positive' | 'default' | 'error'

export interface PasswordRequirement {
  text: string
  status: PasswordRequirementStatus
}
```

`positive` selects a check icon and positive semantic colors, `default` selects
a neutral bullet and default colors, and `error` selects an X icon and danger
colors. All icons are 16px. Status is also exposed as visually hidden text, so
meaning is not conveyed by color or icon alone.

`InputFieldProps` also accepts native
[`InputHTMLAttributes<HTMLInputElement>`](https://react.dev/reference/react-dom/components/input#props),
including `value`, `defaultValue`, `type`, `name`, `required`, event handlers,
and `aria-*` attributes.

## Examples

```tsx
import { InputField } from './components/InputField/InputField'

<InputField
  label="Email address"
  type="email"
  autoComplete="email"
  hasDescription
  description="We will use this address for account updates."
/>
```

### Error message

```tsx
<InputField
  label="Email address"
  state="Error"
  hasError
  error="Please enter a valid email address."
/>
```

### Password

```tsx
import type { PasswordRequirement } from './components/InputField/InputField'

const passwordRequirements: [
  PasswordRequirement,
  PasswordRequirement,
  PasswordRequirement,
] = [
  { text: 'At least 12 characters', status: 'positive' },
  { text: 'Includes uppercase and lowercase letters', status: 'default' },
  { text: 'Includes a number and a symbol', status: 'error' },
]

<InputField
  label="Password"
  type="password"
  showPasswordCaption
  passwordRequirements={passwordRequirements}
/>
```
